# Agent notes

## References

Conversation reference materials (moodboards, style refs, maps, docs, etc.) live under `references/`.

Rules:

1. Store references provided in conversation inside a suitable **subfolder** of `references/` (for example `references/maps/`, `references/style/`).
2. If no existing subfolder fits, **create a new one** with a short, descriptive name.
3. Only archive **references** the user provides for inspiration or guidance.
4. Do **not** put work-in-progress deliverables here — for example tweets or posters the user asked you to write, edit, or produce during the task. Those belong elsewhere (or stay as artifacts), not under `references/`.

When the user shares a new reference, save the file(s) into the right subfolder and keep names clear and stable.
